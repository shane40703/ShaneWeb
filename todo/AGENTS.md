# Todo 維護規則

Todo 有三種狀態：

- 未實作
- 已實作待審核
- 歷史紀錄

Todo 與歷史紀錄的需求分組標題一律使用 `## 1.x - YYYY-MM-DD` 格式，例如
`## 1.12 - 2026-07-28`。保留需求編號，但標題不可加上「需求」兩字或主題名稱。
舊有未編號分組使用 `## 原分組名稱 - YYYY-MM-DD` 格式。

Agent 實作完成後，只能將項目標記為「已實作待審核」，並保留在
`todo.md`，不可自動搬入歷史紀錄。

每完成一個 Todo，必須先建立一個只包含該 Todo 相關變更的獨立 commit，
再開始實作下一個 Todo。

每個 Todo 的 commit 訊息必須使用中文，並清楚描述該 Todo 的變更內容。

只有收到人工明確指令後，才能將待審核項目移到
`歷史紀錄/todo-歷史紀錄.md`。搬移時需保留原本的需求分組，將相關圖片移到
`歷史紀錄/圖片/` 並接續編號，再將參考圖連結更新為 `圖片/image-XX.png`。
