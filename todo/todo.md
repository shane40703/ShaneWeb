### ai agent 實作時的決定

- 邀請連結拿掉了後面的追蹤參數，打開的是同一個群組。QR Code 也是這個連結，已經用程式讀過確認，但還沒用手機和 LINE app 實際掃過。
- 功能建議和錯誤回報集中到 LINE，所以 Threads 的說明拿掉了「或告訴我你希望網站變得更好用的地方」。
- 隱私權政策的聯絡方式維持只寫 Threads：在 LINE 群組裡講刪除資料的事，所有成員都看得到。
- LINE 卡片沒有放 GitHub 連結，原始碼連結放在「開源授權」頁。
- 卡片用網站本身的配色，沒有用 LINE 的綠色。兩張卡片的按鈕都是藍底的主要按鈕；如果覺得太搶眼，可以把 LINE 的改成次要樣式。
