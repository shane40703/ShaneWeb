## 補圖後更新網頁

圖片補入上述來源資料夾後，在專案根目錄執行：

```powershell
node scripts/import-113-question-bank.mjs 115
node scripts/import-written-question-bank.mjs 115
npm.cmd run generate:question-data
```

這些匯入指令會更新 115 年的網站題目檔案；重新匯入前，請確定人工圖片都放在來源資料夾，並保留任何已手動修改的網站題目文字。
